# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |
| 1.x     | No        |

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.

Report privately through [GitHub Security Advisories](https://github.com/iletai/BaseNavigationStack/security/advisories/new). You should get a first response within 7 days. Once a fix is released, the advisory is published with credit to the reporter unless you prefer otherwise.
